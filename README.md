## 🛠️ Troubleshooting (Common Issues)

### Problem: "I downloaded the file but it won't open"

**Solution:** Make sure you extracted the ZIP file completely. Just double-clicking the ZIP to look inside isn't enough. You must right-click and choose "Extract All". Then run the `.exe` file from the extracted folder.

### Problem: "The program says 'No Camera Found'"

**Solution:** 

1. Check your camera is connected (for webcams) or on the same WiFi network (for IP cameras)
2. Close all other programs that might be using the camera (like Zoom or Skype)
3. Restart the franken_surveillance_system program

### Problem: "I don't have enough storage space"

**Solution:** The program uses smart compression to save space. Go to `Settings` -> `Storage` and select "Lower Quality" or "Compressed" mode if you're running low. You can also set it to automatically delete recordings older than 30 days.

### Problem: "Motion detection triggers too often"

**Solution:** This is usually caused by shadows, trees moving, or insects. Go to `Camera Settings` -> `Motion Detection` and lower the sensitivity slider. You can also draw a "zone" around the area you want to monitor - the program will only detect motion inside that area.
